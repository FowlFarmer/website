# Hello, Avalon

*April 25, 2026*

Welcome. This is Avalon — a small corner of my site for writing, notes, and half-formed ideas.

The name is borrowed loosely from the mythical isle: a place set apart, unhurried. That's the feeling I'm going for here. Not a polished publication, not a portfolio piece. Just a place to think out loud.

## What this is

I've always kept notes — scattered across Notion, Apple Notes, random `.txt` files. Avalon is an attempt to make some of those public. Expect:

- **Short essays** on things I've been thinking about
- **Project retrospectives** — the interesting parts that don't fit in a README
- **Reading notes** — ideas borrowed from books and made my own

## What this isn't

This isn't a tech blog optimized for SEO. I'm not going to write "Top 10 React Hooks" posts. If you're looking for tutorials, there are better places.

## Adding a new post

For the curious: each post here is a Markdown file in `public/avalon/posts/`. To add one, drop a `.md` file there and add an entry to `public/avalon/index.json`. That's it.

Thanks for reading.
